# Poetry Archive with PHP + MySQL 

## The Poetry Archive is a personal diary in the albanian language, filled with beloved poems and music from different languages.

***Just for clarification:***
1. Copy the folder to C:\xampp\htdocs\
2. Open XAMPP and turn on Apache + MySQL.
3. Go to http://localhost/phpmyadmin
4. Execute database.sql.
5. Go to http://localhost/poetry/

Pages:
- index.php   = list + search-bar
- db.php      = connection with MySQL

>Credentials on XAMPP:
database: poetry_db,
user: root,
password: empty.
