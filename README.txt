# Poetry Archive with PHP + MySQL 

1. Kopjo folderin poetry ne C:\xampp\htdocs\
2. Hap XAMPP dhe ndiz Apache + MySQL.
3. Hap http://localhost/phpmyadmin
4. Ekzekuto permbajtjen e database.sql.
5. Hap http://localhost/poetry/

Faqet:
- index.php   = lista + kerkimi
- db.php      = lidhja me MySQL

Kredencialet e parazgjedhura XAMPP:
database: poetry_db
user: root
password: bosh
